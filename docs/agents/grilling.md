# One-question grilling format

This format overrides an installed grilling skill's instruction to ask the whole
frontier in one round. Ask one decision, wait for the human answer, and recompute
what remains.

Every reply that asks a decision question uses this order:

1. Explain the actual uncertainty or missing ruling before the options.
2. Use plain words and the facts needed to decide.
3. Give lettered options with the concrete cost beside each.
4. Ask exactly one decision in one block beginning with `❓`.
5. Recommend an option in a line beginning with `➡️`, with reasons.
6. End with `Held for later:` naming deferred decisions, or `nothing.`

When no decision remains, end with this exact line:

**Frontier empty — confirm shared understanding.**

The human confirms shared understanding before implementation begins.
